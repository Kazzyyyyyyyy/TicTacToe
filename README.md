# TicTacToe
First C++ projekt (did 6 leetcode problems before this): simple TTT.

Index to play: 1 - 3.
First enter Y, second X.

CPU starts.
CPU moves are not random. 

CPU does moves (if possible) in order: 
- win
- block player from winning
- filling cell that could lead to win in next round
- claim most powerful cells 
- first free cell possible

Should work on all platforms.
